# Card

## Parts
- Card (root), CardHeader, CardTitle, CardDescription, CardAction, CardContent, CardFooter

## States
Static container; `size` changes shared spacing.

## Props
- `size`: default | sm

## Tokens
card, card-foreground, muted, muted-foreground, foreground (ring at 10%), radius

## Accessibility
Use a heading element inside CardTitle when the card starts a section.
