# Input

## Parts
- Native `<input>`

## States
Default, focus-visible, disabled, invalid (`aria-invalid`), file.

## Props
All native input attributes.

## Tokens
input, border, ring, destructive, muted-foreground, foreground, radius

## Accessibility
Always paired with a Label (`htmlFor`) or `aria-label`; error text linked with `aria-describedby`.
