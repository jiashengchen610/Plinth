# Textarea

## Parts
- Native `<textarea>` that grows with its content

## States
Default, focus-visible, disabled, invalid (`aria-invalid`).

## Props
All native textarea attributes.

## Tokens
textarea-field-background, -foreground, -border, -placeholder; textarea-radius; duration-fast; ring, destructive.

## Accessibility
Paired with a Label (`htmlFor`) or `aria-label`; error text linked with `aria-describedby`.
