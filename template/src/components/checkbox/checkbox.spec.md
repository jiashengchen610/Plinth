# Checkbox

## Parts
- Root (button with role checkbox)
- Indicator (check or minus icon from @/icons)

## States
Unchecked, checked, indeterminate, focus-visible, disabled, invalid.

## Props
Radix Checkbox props: `checked`, `defaultChecked`, `onCheckedChange`, `disabled`, `required`, `name`, `value`.

## Tokens
checkbox-box-background, -border, -checked-background, -checked-foreground, -checked-border; checkbox-radius (radius.small); duration-fast; ring.

## Accessibility
Space toggles. Always labelled; the label is clickable. Indeterminate is announced as mixed.
