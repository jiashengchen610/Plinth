# Tabs

## Parts
- Root
- List (role tablist)
- Trigger (role tab)
- Content (role tabpanel)

## States
Active, inactive, focus-visible, disabled.

## Props
Radix Tabs props: `value`, `defaultValue`, `onValueChange`, `orientation`, `activationMode`.

## Tokens
tabs-list-background, -foreground; tabs-trigger-active-background, -active-foreground; tabs-radius; shadow-card; duration-fast; ring.

## Accessibility
Arrow keys move between tabs; Tab moves into the panel. Each panel is labelled by its tab.
