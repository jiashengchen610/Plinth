# Badge

## Parts
- Root: `<span>` (or the child element with `asChild`)
- Optional leading icon

## States
Static; `link` variant has hover when rendered as an anchor.

## Props
- `variant`: default | secondary | destructive | outline | ghost | link
- `asChild`: boolean

## Tokens
primary, primary-foreground, secondary, secondary-foreground, destructive, muted, muted-foreground, border

## Accessibility
Status must not rely on color alone: the label text carries the meaning.
