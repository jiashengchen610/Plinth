# Empty

## Parts
- Empty: the area (add `border border-dashed` for an outline)
- Header: Media (an icon tile or a picture), Title, Description
- Content: the actions

## States
Plain or outlined.

## Props
Plain element props. `EmptyMedia`: `variant` ("default" or "icon").

## Tokens
empty-radius, empty-border, empty-media-background, -media-foreground, -media-radius, empty-title-font,
empty-description-font, -description-foreground.

## Accessibility
Plain text and buttons. Say what is missing and what to do next, with one main action.
