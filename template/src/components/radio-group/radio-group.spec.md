# Radio group

## Parts
- Root (role radiogroup)
- Item (role radio)
- Indicator (dot)

## States
Unselected, selected, focus-visible, disabled, invalid.

## Props
Radix RadioGroup props: `value`, `defaultValue`, `onValueChange`, `disabled`, `orientation`, `name`, `required`.

## Tokens
radio-group-item-background, -border, -checked; duration-fast; ring.

## Accessibility
Arrow keys move and select; Tab enters and leaves the group. Group labelled with `aria-label` or a heading; each item labelled.
