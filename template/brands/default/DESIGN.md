# Default

A neutral starting brand. Replace this with the brand's own description.

## Overview

Calm, neutral and legible. Color is reserved for actions and status.

## Colors

- primary: the main action color. Use it for one action per view.
- destructive: irreversible actions and errors only.
- muted / muted-foreground: secondary surfaces and supporting text.
- success, warning, info: status only (badges, alerts, inline messages), never for actions.

## Typography

Geist for everything: headings, text, and buttons and labels use the same font until another is picked. Display for
page titles and big numbers, heading styles for section, dialog and card titles, text styles for content, label styles
for buttons, tabs and badges.
